Read this before the numbers

  • Homepages only. Product pages are a different population and are not characterised here.

  • One run, one date. k=1. This edition contains no time series.
  • Convenience sample. 19 of 20 hosts, chosen by category, not drawn at random.
  • No score, no ranking. Per-check results and ratios only.

What this is not

  • Not an AI visibility index. That question is “does a brand appear in AI answers”, it is already well covered, and we do not measure it.
  • Not a score or a ranking. One number per site would need a weighting we cannot defend.
  • Not a claim about agent behaviour. We do not know what any agent read, skipped or bought.

How it was measured

One honest user agent, ordinary HTTP requests, no browser and no JavaScript. Every host received the same three requests; robots.txt was respected and one host was excluded because of it. Six signals, each a deterministic fact about the response. Two independent runs produced zero class changes across 133 checks.
